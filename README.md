# 🧩 Conexão Nominal

**Conexão Nominal** é um jogo de associação de palavras em equipes, no qual os participantes precisam interpretar pistas e identificar corretamente as palavras de seu time.

O jogo combina raciocínio, comunicação e estratégia em partidas com tabuleiros gerados aleatoriamente.

## 🎮 Funcionalidades

- Partidas entre duas equipes.
- Tabuleiros com 16, 20 ou 25 palavras.
- Distribuição aleatória de cartas.
- Sistema de turnos e pontuação.
- Visualização de um mapa secreto para os mestres.
- Regras e condições de vitória implementadas no jogo.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Configure o tabuleiro e inicie uma partida.

Não é necessário instalar dependências externas.

## 📂 Estrutura do projeto

- `index.html` — Interface e telas do jogo.
- `style.css` — Estilização da aplicação.
- `script.js` — Lógica do tabuleiro, turnos e pontuação.
- `palavras.js` — Banco de palavras utilizado nas partidas.

## 📌 Sobre o projeto

O Conexão Nominal foi desenvolvido com foco na utilização de JavaScript para criar interfaces dinâmicas, gerenciar turnos e implementar regras de um jogo interativo.
